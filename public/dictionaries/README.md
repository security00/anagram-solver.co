# Dictionary data

`common.txt` and `full.txt` are normalized, lowercase `a-z` word lists generated
from the English Speller Database (ESDB, previously SCOWLv2):

- `common.txt`: size 35, 38,839 entries after normalization
- `full.txt`: size 70, 142,056 entries after normalization

Source and documentation:

- https://wordlist.aspell.net/
- https://github.com/en-wl/wordlist/tree/v2

These are general English spelling lists, not official Scrabble or other game
lexicons. Regenerate and review the lists when deliberately updating the source;
do not silently mix in a separately licensed game dictionary.
