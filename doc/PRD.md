# Anagram Solver PRD

## Product Overview

Anagram Solver is a free online word tool for finding single-word and multi-word anagrams from letters, names, and phrases. The site targets word game players, puzzle solvers, teachers, students, and casual wordplay users.

## Current Growth Focus

The current Search Console opportunity is the multiple-word anagram cluster:

- multiple word anagram solver
- anagram solver multiple words
- anagram solver 2 words
- two word anagram solver
- three word anagram solver

The site already receives impressions for this cluster, so the near-term goal is to improve click-through rate, page match, and tool usefulness.

## Core Tools

- Main anagram solver: find valid single words from a set of letters.
- Word finder: find words from letters or wildcard patterns.
- Scrabble solver: find high-scoring words from available tiles.
- Multiple word anagram solver: find exact two-word and three-word phrase anagrams.
- Two word anagram solver: focused page for exact two-word results.
- Three word anagram solver: focused page for exact three-word results.

## Multiple-Word Solver Requirements

- Ignore spaces, punctuation, and capitalization.
- Use every input letter exactly once.
- Support exact two-word and exact three-word results.
- Support common and full dictionaries.
- Support minimum word length filtering.
- Support a required word filter.
- Support result count limits.
- Show total Scrabble-style score for each phrase.
- Provide a copy button for phrase results.
- Provide quick example inputs.

## SEO Requirements

- Each tool page should have a unique title, description, H1, canonical URL, and FAQ content.
- Focused pages should not be thin duplicates. Each page needs a clear use case and matching tool defaults.
- The sitemap must include all indexable tool pages.
- Internal links should connect the related anagram pages together.
- Copy should explain real use cases instead of repeating keywords mechanically.
